REST API FullStack (Node + React + TypeScript)
📌 Descripción

Proyecto fullstack que incluye un backend desarrollado con Node.js con Express.js y TypeScript, y un frontend en React. Permite gestionar productos (CRUD completo).

🚀 Tecnologías
Node.js
TypeScript
Express
React
PostgresSQL
⚙️ Instalación
Backend
cd server
npm install
npm run dev
Frontend
cd client
npm install
npm run dev
🔐 Variables de entorno

Crear un archivo .env en la carpeta server con:

PORT=3000
DATABASE_URL=tu_bd_Externa
FRONTEND_URL=tu_URL
📦 Scripts importantes

Backend:

npm run dev → modo desarrollo
npm run build → compilar TypeScript
npm start → ejecutar en producción
